🤖 Supervised Random Forest Regressor Trained ML

A high-speed regressor trained directly on 1,200 realistic SUMO simulation scenarios spanning balanced, peak, directional surges, roadwork closures, and emergency preemption.

  • Training Scenarios: 1,200 records (historical_traffic_dataset.csv)
  • Estimator Trees: 120 decision trees (RandomForestRegressor)
  • NS Green Accuracy: R² = 0.994 | MAE = 0.94s
  • EW Green Accuracy: R² = 0.993 | MAE = 0.95s
  • Inference Latency: < 1 millisecond
🧠 Gemini Generative AI Strategist Generative AI

Multi-agent architecture leveraging Gemini with an Model Context Protocol (MCP) tool-call layer for contextual zero-shot bottleneck reasoning and chain-of-thought strategy synthesis.

  • Agent 1 (Strategist): Evaluates directional ratios, lane blocks & emergencies
  • Agent 2 (Evaluator): Synthesizes SUMO physics feedback & ranks strategies
  • MCP Tools: Closed-loop SUMO simulation, scenario generator, and perception tools
  • Fallback Engine: Deterministic offline heuristics for 100% availability
